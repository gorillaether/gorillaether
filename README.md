## What This Was

GorillaEther was an institutional-grade macroeconomic and
fixed-income intelligence platform built over 3+ years,
bridging traditional finance and DeFi infrastructure.

**Core Architecture**
- Decoupled React frontend + Python/FastAPI backend
- Google Cloud Run — serverless, zero-latency data delivery
- Custom macro physics engine: 2nd-derivative acceleration
  on US Treasuries and global capital flows
- Signal framework: PCE velocity/acceleration, yield curve
  dynamics, stablecoin dominance, liquidity tracking

**Web3 & DApp Research**
Polygon EVM, Solidity, Solana/Rust/Anchor, Hardhat/Ignition,
Privy embedded wallets, decentralized identity (soulbound NFTs),
ergodicity modeling, on-chain financial simulation.
